# تحديث ميدان على iOS خارج Replit

هذا مشروع UIKit وWKWebView مستعاد من الحزمة المحفوظة `maydan-mobile-beta-0.9.2.zip` (نسخة 2026-09-01). يشغّل اللعبة والوسائط من داخل التطبيق. المصدر المستعاد يحمل المعرّف `com.maydan.game` والإصدار `0.9.2` والبناء `3`؛ هذه قيم النسخة المحفوظة وليست تأكيدًا لقيم التطبيق المنشور عبر Replit.

## المحتوى والبناء

شغّل `npm ci` ثم `npm run ios:prepare` من جذر المستودع. الأمر الأخير يبني محتوى الفرع الحالي، وينسخ جميع ملفات اللعبة والوسائط إلى حزمة iOS، ويتحقق من تطابق كل ملف. المجلد الناتج غير متتبّع في Git، لذلك يجب تشغيل الأمر قبل كل بناء في Xcode.

افتح `ios/Maydan.xcodeproj` واختر مخطط `Maydan`. لا يعتمد المشروع على Replit أو CocoaPods أو Expo. محفوظات اللعبة تستخدم مخزن WebKit الدائم في هذا الغلاف، لكن انتقال المحفوظات من تطبيق Replit المنشور لا يمكن ضمانه قبل معرفة غلافه وأصل تخزينه واختبار التحديث فوقه.

يشغّل `iOS build` على GitHub فحوص اللعبة ثم يبني تطبيقًا لمحاكي iPhone/iPad باستخدام Xcode 26 أو أحدث. الملف الناتج مخصص للمحاكي، ولا يمكن تثبيته على هاتف حقيقي أو إرساله إلى App Store. هذا يثبت قابلية الترجمة فقط، ولا يغني عن تجربة التطبيق على جهاز حقيقي.

## قبل إنشاء تحديث المتجر

1. اقرأ Bundle ID ورقم الإصدار المنشور من صفحة تطبيق ميدان الحالي في App Store Connect، وطابق كذلك الأجهزة المدعومة والأيقونة وميزات التطبيق. لا تنشئ سجل تطبيق جديد.
2. حدّد Apple Developer Team الحالي. اضبط Bundle Identifier على معرّف التطبيق المنشور، وVersion على رقم أعلى، وBuild على رقم جديد. لا تُعامل قيم النسخة التجريبية المستعادة كقيم متجر موثوقة.
3. افتح المشروع في Xcode 26 أو أحدث، وحدّد فريق التوقيع، وابنِ Archive، ثم اختبر النسخة عبر TestFlight، خصوصًا التحديث فوق التطبيق القديم والحفظ والوسائط والحركة والاتجاهين.
4. ارفع البناء إلى سجل التطبيق الحالي، وأنشئ إصدارًا مطابقًا له في App Store Connect، ثم اختره وأرسل الإصدار لمراجعة Apple.

يمكن تشغيل التوقيع والرفع أيضًا على macOS في GitHub Actions بعد تجهيز شهادة التوزيع وملف provisioning وحساب App Store Connect. هذه البيانات غير متاحة في المشروع ولا تُحفظ في Git. تستخدم GitHub Secrets عند تفعيل هذه الخطوة؛ لا ترسل كلمات المرور أو المفاتيح الخاصة في المحادثة.

## الحالة الحالية

أُعيد المشروع ووُصل ببناء اللعبة الحالية. لم يُنشأ IPA موقّع، ولم يُرسل تحديث إلى Apple، ولم تُثبت مطابقة هوية تطبيق Replit المنشور بعد. فئة الرأس/حساس الحركة وبقية ميزات المنصة تحتاج اختبارًا داخل WKWebView؛ لا يُدَّعى تكافؤ كامل مع Safari أو نسخة Replit من نجاح الترجمة وحده.

المراجع: [رفع بناء إلى Apple](https://developer.apple.com/help/app-store-connect/manage-builds/upload-builds/)، [إنشاء إصدار جديد](https://developer.apple.com/help/app-store-connect/update-your-app/create-a-new-version/)، [متطلبات SDK الحالية](https://developer.apple.com/news/upcoming-requirements/)، [التوقيع على GitHub Actions](https://docs.github.com/en/actions/how-tos/deploy/deploy-to-third-party-platforms/sign-xcode-applications).
