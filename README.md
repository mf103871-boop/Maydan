# ميدان: ألعاب جمعتنا

ألعاب جماعية عربية تُلعب على **جهاز واحد** يتناقله الأصدقاء والعائلة. تعمل
**دون إنترنت** ولا تُرسل أي بيانات إلى أي مكان: المخرج ملف HTML واحد مكتفٍ
بذاته، بلا CDN ولا خطوط خارجية ولا أي طلب شبكة وقت التشغيل.

الاستثناء الوحيد وسائط حزم «بَديهة» (صور وأصوات ومقاطع): تُجلب من الشبكة أول
مرة ثم تُحفظ في الجهاز للّعب دون اتصال. صيغة الحزم وأنواع الأسئلة في
[`docs/PACK_FORMAT.md`](docs/PACK_FORMAT.md).

**اللعب الآن:** <https://mf103871-boop.github.io/Maydan/>

## الألعاب

| اللعبة | الفكرة | اللاعبون | المدة |
| --- | --- | --- | --- |
| **بَديهة** | لوحة أسئلة من ست فئات، شرائح 200–1000، وسائل مساعدة وسرقات | 2–4 فرق | 20–40 د |
| **قبل ما يطق!** | اذكر ثلاثة قبل الصفارة، أو مرّر القنبلة قبل أن تنفجر بيدك | 2–10 | 10–15 د |
| **ممنوع!** | صف الكلمة دون نطق خمس كلمات ممنوعة، والخصم يراقب | 2–4 فرق | 10–20 د |
| **على جبينك** | الجوال على جبينك، والآخرون يصفون وأنت تخمّن | 2–10 | 10–15 د |
| **فَبْرَكة** | اكتب كذبة مقنعة، واكتشف الحقيقة بين الأكاذيب | 3–8 | 15–25 د |
| **مين فينا؟** | عبارة، عدّ تنازلي، والكل يشير في اللحظة نفسها | 3–12 | 10–20 د |

## التشغيل

```bash
npm install
npm run dev      # يبني dist/ عند كل تغيير ويخدمه على http://localhost:3000
npm test         # اختبارات المنصة والألعاب والمحتوى
npm run build    # dist/index.html — ملف واحد مكتفٍ بذاته

npm run bank:report                    # حالة الفئات الثمانين × الشرائح
npm run bank:validate -- <id>          # فحص فئة (أو البنك كله بلا معامل)
npm run bank:sort -- <id>              # ترتيب الملف وإعادة توليد index.js
npm run media:fetch -- <id> "<بحث>" image --qid <qid>   # وسيط مفتوح الرخصة
npm run release  # release/maydan-platform-<version>.html + أرشيف المصدر
```

## كيف تُضاف لعبة جديدة

اللعبة **وحدة مستقلة**: مجلد تحت `src/games/` يصدّر manifest، وسطر واحد في السجل.

**1) المنطق أولًا** في `logic.js` — آلة حالة نقية بلا React، لتُختبر وحدها:

```js
export function initialState(players, options) { /* … */ }
export function reduce(state, action) { /* … */ }
export function standings(state) { /* … */ }
```

**2) الواجهة** في `Game.jsx` تستقبل `{ api, players, teams, onExit }`، و`api` هو
كل ما تحتاجه من المنصة:

| الحقل | الوظيفة |
| --- | --- |
| `api.sound.play(name)` | مؤثر صوتي مُصنَّع (`correct`, `buzzer`, `explosion`, `drumroll`…) |
| `api.haptics.vibrate(kind)` | اهتزاز (`success`, `error`, `light`…) حيث يتوفر |
| `api.confetti.fire() / .burst()` | قصاصات على canvas، تحترم «تقليل الحركة» |
| `api.toast(msg)` | تنبيه ينزلق من الأسفل |
| `api.storage` | تخزين بنطاق `maydan:<gameId>:` لا يتداخل مع غيره |
| `api.roster` | دفتر اللاعبين المشترك |
| `api.setInGame(bool)` | يفعّل تأكيد الخروج أثناء اللعب |
| `api.restart()` / `api.backToSetup()` | إعادة الجولة أو العودة للإعداد |

**3) المحتوى** في `src/data/games/<id>/*.json`، ويُسحب عبر
`createNoRepeat` من `shared/lib` كي لا يتكرر عنصر داخل اللعبة الواحدة.

**4) الـmanifest** في `index.js`، وبياناته النصية في `meta.js` (خالٍ من React
حتى تختبره في Node):

```js
export default {
  id: 'mygame',
  name: 'اسم اللعبة',
  tagline: 'سطر واحد يصف الفكرة',
  description: 'فقرة تظهر في شاشة التفاصيل',
  howToPlay: ['خطوة', 'خطوة', 'خطوة'],
  accent: '#F5B82E',                                  // أضف --g-mygame في tokens.css
  players: { min: 2, max: 8, mode: 'individual' },    // 'teams' | 'individual' | 'both'
  duration: '10–15 دقيقة',
  tags: ['سرعة'],
  isNew: true,
  version: '1.0.0',
  icon: MyIcon,          // SVG مضمّن
  Component: Game,
  SetupOptions,          // اختياري: إعدادات تظهر في شاشة الإعداد
};
```

**5) التسجيل**: سطر استيراد في `src/platform/registry.js`، ولون
`--g-<id>` في `tokens.css`. الاختبارات تفرض الحقول والألوان.

**6) الاختبارات**: `tests/<id>-logic.test.js` لتقلبات الحالة والحالات الحدية،
وفحص المحتوى يُضاف إلى `tests/games-content.test.js`.

## القيود التي يفرضها البناء والاختبارات

- **صفر طلبات شبكة في المنصة والألعاب**: لا CDN ولا خطوط خارجية. الأيقونات SVG
  مضمّنة، وأصوات الواجهة مُصنَّعة بـ WebAudio. الاستثناء وسائط حزم بَديهة، تُخدَم
  من `media/` في الموقع نفسه وتُحفظ في مخزن العامل الخدمي.
- **بنك بَديهة**: يُبنى فئةً فئة (80 فئة مختارة، 48 سؤالًا في كل شريحة من 200 إلى
  1000). القواعد في [`docs/bank/RUBRIC.md`](docs/bank/RUBRIC.md)، والبنية في
  [`docs/bank/SCHEMA.md`](docs/bank/SCHEMA.md)، والحالة في `src/data/bank-status.json`.
  `npm run bank:validate` يرسب على أي مخالفة: تكرار بعد التطبيع العربي، تجاوز حدود
  الكلمات، ملف غير مرتّب، وسيط بلا ترخيص مقبول أو فوق الميزانية.
- **محتوى الألعاب الجديدة**: حدود دنيا مفروضة في الاختبارات (200 / 200 / 8×30 /
  120 / 150)، ولا تكرار بعد تطبيع النص العربي.
- **لا تكرار عبر الجولات**: `buildDeck` و`createNoRepeat` يقدّمان ما لم يُعرض بعد.

## الوصولية والهاتف

أهداف لمس ≥ 48px، تباين مضبوط، `aria-label` لكل زر أيقوني، حصر التركيز في
النوافذ، احترام `prefers-reduced-motion` (وخيار يدوي في الإعدادات)، ودعم
`env(safe-area-inset-*)` و`100dvh`. المؤقت يتوقف عند فقدان التركيز أو قفل
الشاشة ويستأنف بعد عدّ 3-2-1، والشاشة تبقى مضاءة أثناء اللعب عبر Wake Lock.

## النشر

كل دفعة إلى `main` تشغّل الاختبارات ثم البناء ثم النشر على GitHub Pages عبر
[`.github/workflows/pages.yml`](.github/workflows/pages.yml). الموقع هو `dist/`:
الملف الواحد مع ملفات التطبيق القابل للتثبيت (PWA) من `public/`.

عند تغيير `index.html` المبني، **ارفع رقم `CACHE` في `public/sw.js`**. هذا الرقم
هو ما يميّز الإصدارات: عند تغيّره يحذف العامل الجديد المخزن القديم، ولأن
الصفحة المفتوحة تكون قد جاءت من ذلك المخزن (أي تعرض الإصدار السابق) يعيد
العامل تحميلها بنفسه من `activate`. الصفحة لا تستطيع إصلاح ذلك وحدها لأن الشيفرة
التي تفعل ذلك موجودة في المستند الجديد الذي لم يصلها بعد. النتيجة: تحديث واحد
بدل فتحتين. إن نسيت رفع الرقم بقي اللاعبون على النسخة القديمة.
