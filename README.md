# ميدان — لعبة أسئلة جماعية

لعبة مسابقات عربية للعب الجماعي، من فريقين إلى أربعة. **43 فئة** و**1032 سؤالًا**،
تعمل بالكامل **دون إنترنت**.

## اللعب الآن

<https://mf103871-boop.github.io/-/>

## التثبيت على الهاتف

اللعبة تطبيق ويب قابل للتثبيت (PWA): أيقونة على الشاشة الرئيسية، تعمل بملء الشاشة
دون أشرطة المتصفح، وتشتغل دون إنترنت بعد أول فتح.

- **أندرويد (Chrome):** افتح الرابط، ثم اضغط زر «تثبيت» الذي يظهر أسفل الشاشة —
  أو من قائمة المتصفح ⋮ اختر «تثبيت التطبيق».
- **آيفون (Safari):** افتح الرابط، اضغط زر المشاركة، ثم «إضافة إلى الشاشة الرئيسية».

## البنية

الملف كله قائم بذاته — لا مكتبات تُحمّل من الإنترنت ولا خوادم ولا اتصالات خارجية.

| الملف | الوظيفة |
| --- | --- |
| `index.html` | اللعبة كاملة: React مضمّن، بنك الأسئلة، الأنماط، ومنطق اللعب |
| `manifest.webmanifest` | تعريف التطبيق: الاسم، الأيقونات، وضع ملء الشاشة، الألوان |
| `sw.js` | التخزين المؤقت للعمل دون إنترنت |
| `icons/` | أيقونات التطبيق (عادية و maskable لأندرويد) |

## النشر

يُنشر تلقائيًا على GitHub Pages عند كل دفعة إلى `main` عبر
[`.github/workflows/pages.yml`](.github/workflows/pages.yml).

عند تحديث `index.html`، ارفع رقم `CACHE` في `sw.js` وإلا بقي اللاعبون المثبِّتون
على النسخة القديمة.
