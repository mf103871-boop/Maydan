# ميدان: ألعاب جمعتنا

ألعاب جماعية عربية على **جهاز واحد**، وغرف للعبتَي **مين فينا؟ وفبركة** من
**عدة هواتف**. إصدار 1.4.0 يضيف الكتابة المتزامنة والتصويت السري والكشف
المشترك لفبركة، بالرمز والرابط وQR عبر Cloudflare Workers وSQLite Durable Objects.

ألعاب الجهاز الواحد تعمل دون إنترنت بعد تنزيل المحتوى. الغرف تحتاج الإنترنت
وترسل بيانات الجلسة لخادم الغرف. إعداد الخادم المجاني وتشغيل التجربة في
[`docs/ONLINE.md`](docs/ONLINE.md). عنوان الخادم غير معيّن في هذه الحزمة؛
إعداده شرط لتفعيل الغرف في النشر المنفصل. عند نشر الموقع كاملًا على
Cloudflare، يُضبط عنوان الغرف تلقائيًا إلى عنوان الموقع نفسه.

وسائط حزم «بَديهة» (صور وأصوات ومقاطع) تُجلب من الشبكة أول مرة ثم تُحفظ
في الجهاز للّعب دون اتصال. صيغة الحزم وأنواع الأسئلة في
[`docs/PACK_FORMAT.md`](docs/PACK_FORMAT.md).

**اللعب الآن:** [ميدان](https://maydan-game.mf103871.workers.dev/#/) · [غرف فبركة](https://maydan-game.mf103871.workers.dev/#/online/fabraka)

**تحديث 25 سبتمبر 2026 منشور:** بنك بديهة من 78 فئة و3,120 سؤالًا، مع الصور والأصوات المعتمدة. [تجربة بديهة](https://maydan-game.mf103871.workers.dev/#/play/badeeha) · [سجل الدمج والنشر والتحقق](docs/releases/2026-09-25/README.md).

| **قبل ما يطق!** | اذكر ثلاثة قبل الصفارة، أو مرّر القنبلة قبل أن تنفجر بيدك | 2–10 | 10–15 د |

| **مين فينا؟** | عبارة، عدّ تنازلي، والكل يشير في اللحظة نفسها | 3–12 | 10–20 د |

**فبركة 3** تستبدل البنك السابق بالكامل: **100 سؤال حقائق، و32 صورة توضيحية، و48 سؤال أصحاب، كلها جديدة**.
للحقائق والأدوات روابط مصادر وتواريخ تحقق؛ الصور مولدة بالذكاء الاصطناعي لأدوات حقيقية، مع إفصاح ظاهر ووصف محايد وتكبير.
تُحفظ صور فبركة كلها للعمل دون اتصال بعد اكتمال تثبيت PWA، وتُضمّن في موارد غلاف iOS؛ يلزم نشر `dist` كاملًا مع `media`.
الجلسات المحلية القديمة تبدأ من جديد بسبب استبدال المحتوى، مع الاحتفاظ بالنتائج المكتملة والحسابات.
بقيت النقاط والمؤقّت الاختياري والمساعدة وجائزة الضحك كما هي. تدعم الغرف الأنماط الأربعة لـ3–8 لاعبين؛
لا تكشف رسائل الخادم هوية الإجابة الصحيحة أو روابط المصادر قبل مرحلة الكشف، والمؤقّت يستمر عند إخفاء الصفحة.
[القواعد والمصادر واختبارات القبول](docs/FABRAKA.md). هذا وصف محتوى المستودع، وليس إعلان نشر النسخة الحية.

## النشر على Cloudflare

لنشر اللعبة والغرف معًا على رابط واحد اتبع [`docs/CLOUDFLARE.md`](docs/CLOUDFLARE.md).
يمكن الربط والنشر من متصفح الهاتف عبر Workers Builds، باستخدام فرع `main`.
ملف `wrangler.jsonc` الافتراضي ينشر اللعبة والغرف معًا.
الأمر `npm run cloudflare:deploy` يبني الموقع ويرفعه مع الخادم؛
أما `npm run rooms:deploy` فيرفع خادم الغرف وحده.

## التشغيل

تحتاج Node.js 22 أو أحدث. استخدم `npm ci` لتثبيت إصدارات الحزمة المحفوظة.

```bash
npm install
npm run dev      # يبني dist/ عند كل تغيير ويخدمه على http://localhost:3000
npm test         # اختبارات المنصة والألعاب والمحتوى
npm run build    # dist/index.html مع media والأصول اللازمة؛ انشر dist كاملًا

npm run bank:report                    # حالة الفئات الثماني والسبعين × الشرائح
npm run bank:validate -- <id>          # فحص فئة (أو البنك كله بلا معامل)
npm run bank:placeholders              # قائمة الأسئلة الحشو المُولَّدة آليًا
npm run bank:status -- <id>            # حالة فئة وأعدادها (وبـ done|pending يحدّثها)
npm run bank:sort -- <id>              # ترتيب الملف وإعادة توليد index.js
npm run media:fetch -- <id> "<بحث>" image --qid <qid>   # وسيط مفتوح الرخصة
npm run release  # release/maydan-platform-<version>.html + أرشيف المصدر
```

المعاينة عبر `scripts/dev.mjs` تخدم ملفات اللعبة فقط؛ لا تشغّل خادم الحسابات.
إذا عرضت بها بناء Cloudflare فإن مسارات `/api/` تُرجع `PREVIEW_ONLY`، وتعرض
شاشة الدخول رابط الموقع المنشور بدل الانتقال إلى صفحة مفقودة. للدخول الحقيقي
استخدم [إعدادات الموقع المنشور](https://maydan-game.mf103871.workers.dev/#/settings).
اختبار الحسابات محليًا يحتاج خادم الاختبار الموثق في [دليل الحسابات](docs/ACCOUNTS.md)؛
تغيير عنوان API إلى الإنتاج وحده لا يسمح بالعودة إلى localhost، ولا ينبغي تجاوز
قائمة أصول المصادقة المسموحة أو تعطيل التحقق منها.

```
  shared/

    setup/                     دفتر اللاعبين، إعداد الفرق، شاشة «سلّم الجوال»

```

## كيف تُضاف لعبة جديدة

اللعبة **وحدة مستقلة**: مجلد تحت `src/games/` يصدّر manifest، وسطر واحد في السجل.

**1) المنطق أولًا** في `logic.js` — آلة حالة نقية بلا React، لتُختبر وحدها:

```js
export function initialState(players, options) { /* … */ }
export function reduce(state, action) { /* … */ }
export function standings(state) { /* … */ }
```

**2) الواجهة** في `Game.jsx` تستقبل `{ api, players, teams, onExit }`، و`api` هو
كل ما تحتاجه من المنصة:

| الحقل | الوظيفة |
| --- | --- |
| `api.sound.play(name)` | مؤثر صوتي مُصنَّع (`correct`, `buzzer`, `explosion`, `drumroll`…) |
| `api.haptics.vibrate(kind)` | اهتزاز (`success`, `error`, `light`…) حيث يتوفر |
| `api.confetti.fire() / .burst()` | قصاصات على canvas، تحترم «تقليل الحركة» |
| `api.toast(msg)` | تنبيه ينزلق من الأسفل |
| `api.storage` | تخزين بنطاق `maydan:<gameId>:` لا يتداخل مع غيره |
| `api.roster` | دفتر اللاعبين المشترك |
| `api.setInGame(bool)` | يفعّل تأكيد الخروج أثناء اللعب |
| `api.restart()` / `api.backToSetup()` | إعادة الجولة أو العودة للإعداد |
| `api.resumeGame(snapshot)` | استئناف لقطة فحصتها اللعبة، مع لاعبيها وإعداداتها؛ تصل في `savedSession` |
| `api.setGameOptions(options)` | تمرير إعدادات الإطلاق في `gameOptions` حتى عند تعذر حفظ التفضيلات |
| `api.setSetupValid(bool)` | تمكين بدء اللعب بحسب صلاحية خيارات المحتوى |
| `api.setBeforeExit(handler)` / `api.setExitMessage(text)` | إخفاء الدور أو إيقاف المؤقّت قبل تأكيد الخروج، ووصف حالة الحفظ بدقة |

**3) المحتوى** في `src/data/games/<id>/*.json`، ويُسحب عبر
`createNoRepeat` من `shared/lib` كي لا يتكرر عنصر داخل اللعبة الواحدة.

**4) الـmanifest** في `index.js`، وبياناته النصية في `meta.js` (خالٍ من React
حتى تختبره في Node):

```js
export default {
  id: 'mygame',
  name: 'اسم اللعبة',
  tagline: 'سطر واحد يصف الفكرة',
  description: 'فقرة تظهر في شاشة التفاصيل',
  howToPlay: ['خطوة', 'خطوة', 'خطوة'],
  accent: '#F5B82E',                                  // أضف --g-mygame في tokens.css
  players: { min: 2, max: 8, mode: 'individual' },    // 'teams' | 'individual' | 'both'
  duration: '10–15 دقيقة',
  tags: ['سرعة'],
  isNew: true,
  version: '1.0.0',
  icon: MyIcon,          // SVG مضمّن
  Component: Game,
  SetupOptions,          // اختياري: إعدادات تظهر في شاشة الإعداد
};
```

**5) التسجيل**: سطر استيراد في `src/platform/registry.js`، ولون
`--g-<id>` في `tokens.css`. الاختبارات تفرض الحقول والألوان.

**6) الاختبارات**: `tests/<id>-logic.test.js` لتقلبات الحالة والحالات الحدية،
وفحص المحتوى يُضاف إلى `tests/games-content.test.js`.

## القيود التي يفرضها البناء والاختبارات

- **صفر طلبات شبكة في المنصة والألعاب**: لا CDN ولا خطوط خارجية. الأيقونات SVG
  مضمّنة، وأصوات الواجهة مُصنَّعة بـ WebAudio. الاستثناء وسائط حزم بَديهة، تُخدَم
  من `media/` في الموقع نفسه وتُحفظ في مخزن العامل الخدمي.
- **بنك بَديهة**: يُبنى فئةً فئة (78 فئة، منها 10 فئات وسائط؛ 77 مكتملة و`beforeafter`
  قيد العمل؛ 48 سؤالًا في كل شريحة من 200 إلى 1000). `childhood` أُسقطت لتعذّر
  ترخيص صور الطفولة ([`docs/bank/review-childhood-removed-2026-09-09.md`](docs/bank/review-childhood-removed-2026-09-09.md))،
  و`fourpics` سُحبت لأن صورها من مجمّع مشترك لا يخصّ إجاباتها
  ([`docs/bank/review-fourpics-removed-2026-09-15.md`](docs/bank/review-fourpics-removed-2026-09-15.md)).
  القواعد في [`docs/bank/RUBRIC.md`](docs/bank/RUBRIC.md)، والبنية في
  [`docs/bank/SCHEMA.md`](docs/bank/SCHEMA.md)، والحالة في `src/data/bank-status.json`.
  `npm run bank:validate` يرسب على أي مخالفة: تكرار بعد التطبيع العربي، تجاوز حدود
  الكلمات، ملف غير مرتّب، وسيط بلا ترخيص مقبول أو فوق الميزانية، وحشو مُولَّد آليًا
  (`npm run bank:placeholders` يطبع القائمة كاملة).
- **محتوى الألعاب الجديدة**: حدود دنيا مفروضة في الاختبارات (200 / 200 / 8×30 /
  120 / 150)، ولا تكرار بعد تطبيع النص العربي.
- **لا تكرار عبر الجولات**: `buildDeck` و`createNoRepeat` يقدّمان ما لم يُعرض بعد.
- لوحات الرسوم الصلصالية (`src/shared/brand/assets/{avatars,game-icons,trophy}.webp`) شفافة الحواف وتُولَّد من الأصول المسطّحة في `assets/flat/` بأمر `npm run art:alpha`؛ `npm run art:check` (ويشغّله `npm test`) يرسب إن فقدت قناة الألفا. لا تُحرَّر المخرجات يدويًا ولا يعاد استعمال `mix-blend-mode`/القص الدائري لإخفاء الخلفية.

## الوصولية والهاتف

أهداف لمس ≥ 48px، تباين مضبوط، `aria-label` لكل زر أيقوني، حصر التركيز في
النوافذ، احترام `prefers-reduced-motion` (وخيار يدوي في الإعدادات)، ودعم
`env(safe-area-inset-*)` و`100dvh`. المؤقت يتوقف عند فقدان التركيز أو قفل
الشاشة ويستأنف بعد عدّ 3-2-1، والشاشة تبقى مضاءة أثناء اللعب عبر Wake Lock.

## النشر

كل دفعة إلى `main` تشغّل الاختبارات ثم البناء ثم النشر على GitHub Pages عبر
[`.github/workflows/pages.yml`](.github/workflows/pages.yml). الموقع هو `dist/`:
الملف الواحد مع ملفات التطبيق القابل للتثبيت (PWA) من `public/`.

اسم مخزن العامل الخدمي **لا يُحرَّر يدويًا**. القيمة في `public/sw.js` هي
`maydan-platform-__BUILD_ID__`، ويستبدلها البناء (`buildId` و`copyPublic` في
`scripts/lib.mjs`) بالإصدار مع بصمة sha256 لمستند `index.html` المبني. أي تغيير
في المستند يُنتج اسم مخزن جديدًا تلقائيًا: العامل الجديد يحذف المخزن القديم من
`activate`، ولأن الصفحة المفتوحة تكون قد جاءت من ذلك المخزن (أي تعرض الإصدار
السابق) يعيد العامل تحميلها بنفسه. الصفحة لا تستطيع إصلاح ذلك وحدها لأن الشيفرة
التي تفعل ذلك في المستند الجديد الذي لم يصلها بعد. النتيجة: تحديث واحد بدل
فتحتين، بلا خطوة يدوية تُنسى. وضع رقم ثابت مكان `__BUILD_ID__` يُعطِّل هذا
الوسم التلقائي.

ملف `public/_headers` يرافق `dist/` ويحمل ترويسات الأمان (CSP، `nosniff`،
`X-Frame-Options`، `Referrer-Policy`) نفسها التي يضعها `server/full-worker.mjs`،
لأن `assets.run_worker_first` في `wrangler.jsonc` يقصر تشغيل العامل على
`/api` و`/health` فلا يمرّ الملف الثابت به.
