# تغطية استوديو ميدان

سجل العناصر في [coverage.json](./coverage.json) يربط **96 شاشة وحالة** بـ**803 تعريفات عنصر**. منها 703 أزواج شاشة وعنصر ظهرت في مكونات اللعبة داخل اختبار المتصفح، و100 تعريف مشروط يحمل سببًا محددًا في السجل. لا يُضاف عنصر لكل شاشة افتراضيًا لمجرد وجوده في شاشة أخرى.

تستخدم المعاينة مكونات اللعبة الحالية مع سياقات حساب وأصدقاء وصوت وغرف تجريبية. يعزل إطار المعاينة التخزين والاتصال والميكروفون قبل استيراد المكونات. بنك إجابات ارسمها يبقى على الخادم؛ كلمات المعاينة بيانات ثابتة مستقلة.

## الحدود المحمية

- لا يمكن إخفاء مسار مطلوب للرجوع أو الخروج أو الحساب أو الخصوصية أو الإبلاغ، ولا جعل شفافية العنصر المحمي أقل من الحد المسموح.
- لا تغيّر حقول النص السؤال أو الحل أو نقاط اللاعب أو هويته أو معنى لون أداة الرسم. سجل العنصر يحدد النص والأيقونة والأنماط المسموح بتعديلها.
- كشف الأدوار السرية والتخمين الصحيح وصلاحيات الرسم والكتم تبقى شروطًا في مكونات اللعبة، مستقلة عن التصميم.
- لوحة ارسمها تبقى مربعة. الصفوف المتكررة تُحرّك بإزاحة تحافظ على ترتيبها. موضع دوائر المكالمة الشخصي يظل قابلًا للسحب بعد التخصيص.
- نافذة شراء Apple والكيبورد وواجهات النظام الأصلية تحتفظ بتصميم النظام. حالة الكيبورد في الاستوديو محاكاة لمساحته.

## الحالات الشرطية

تظهر أسباب الحالات الشرطية بجانب كل تعريف في السجل، مثل تسجيل الصوت الحقيقي ومراجعة تسجيل محلي، إعادة الاتصال بعد الانقطاع، استعادة مباراة محفوظة، أنواع وسائط بديهة، تغيير علاقة الصداقة، حذف صورة البروفايل ونتيجة تعاون شخصين. لا تدخل المعاينة إلى ميكروفون المستخدم أو رسائله لتحقيق تغطية شكلية. شريط HomeGroups المصدّر غير المركب في الصفحة الرئيسية الحالية موثّق بهذه الحالة.

## فحوص إعادة التشغيل

| الفحص | الأمر |
|---|---|
| البنك الدلالي والعقود والصلاحيات والتخزين | `npm test` |
| الشاشات الفعلية والعناصر الظاهرة | `node tests/e2e/design-semantic-coverage.mjs` |
| واجهة الاستوديو والحفظ والتحريك وحالات المقاسات | `node tests/e2e/studio.mjs` |
| هوية عناصر React والكتابة والسحب ودوائر المكالمة | `node --test tests/e2e/design-render.mjs` |
| صحة الأنماط والمراجع | `npm run lint` |

اختبارات المعاينة تغطي المكونات ببيانات معزولة، ولا تستبدل إكمال مباريات فعلية وتجربة الكيبورد والمكالمات على iPhone. يبقى نشر التصميم العام مقفلًا إلى أن تنجح تجربة الجهاز.
