ميدان بلس — النطاق الحالي بعد إلغاء تجربة المجلس، 2 نوفمبر 2026

واجهة اللعب والقوائم والغرف تستخدم الشكل السابق لتجربة المجلس الحي.
أُزيل المجلس والطاولات والشخصيات المجسّمة من التطبيق ومن أصول التشغيل.

مزايا العضوية الحالية:
1. شكل البروفايل: ألوان وخلفية وأسطح متناسقة داخل الملف الشخصي.
2. إطار الصورة الشخصية، مستقل عن اختيار شكل البروفايل.

اختيار الإطار المعتمد: «هادئ». يحتفظ بإطار ميدان الذهبي نفسه، مع وهج محدود ولمعة تدور ببطء كل 11 ثانية في البروفايل. الصور الصغيرة والمتوسطة ثابتة، ولا شرارات. تتوقف الحركة خارج الشاشة وفي الخلفية، وتختفي عند تفعيل تقليل الحركة. يبقى مؤشر المتحدث الأخضر واضحًا.

تطبيق البروفايل أو الإطار لا يستبدل الصورة الشخصية أو الاسم.
تبقى الألعاب والحزم وإنشاء الغرف والانضمام إليها والمحادثات والمكالمات مجانية.
لم تتغير منتجات StoreKit الشهرية والسنوية أو أسعارها، ولم تتحول الحسابات المجانية إلى حسابات مشتركة.

الاختيارات القديمة محفوظة. تُقرأ الرسائل والملصقات القديمة كما كانت، وتبقى قراءة وحذف الإعدادات المحفوظة القديمة متاحتين. لا تُمنح مزايا الغرف أو الملصقات أو التفاعلات الخاصة أو حفظ الجلسات بمجرد الاشتراك الحالي. حقوق المقتنيات الدائمة المثبتة تبقى متوافقة.
