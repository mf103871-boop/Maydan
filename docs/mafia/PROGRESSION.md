# تقدم مافيا ميدان — سياسة المعاينة 1

يملك الحساب تقدم مافيا مستقلًا عن إحصاءات الألعاب العامة وعن سجل النتائج المحتفظ به 30 يومًا. لا تغير الخبرة أو الإتقان توزيع الأدوار أو الشحنات أو القدرات.

## البداية والنتيجة

يصدر الخادم `rewardPolicyVersion=1` عند بدء مباراة بروتوكول 2 مع `MAFIA_PROGRESS_ENABLED=1`. المباريات السابقة أو التي بدأت والبوابة مغلقة لا تكتسب أهلية بأثر رجعي عند النهاية. حسابات البداية مثبتة داخل `statsMatch.accounts`، ولا تُستبدل بحساب آخر يستعمل المقعد لاحقًا.

ينتج حدث `match_completed` خادمي واحد بالمفتاح المرجعي الحالي للغرفة والمباراة، ومعه معرف إحصاءات البروفايل نفسه ونسخة المخطط والقواعد والسياسة ووقت البداية والنهاية وإعدادات المباراة وحقائق المشاركين. لا يتضمن محادثات أو صوتًا. يستخدم البروفايل والأرشيف هذه الحقائق نفسها؛ مستهلك التقدم لا يعيد تسجيل `player_events` العامة.

تُحفظ النتيجة مع outbox في معاملة Durable Object. يصرف الخادم الأرشيف ثم التقدم بعد 30 ثانية على الأقل. لا يُحذف الحدث إلا عند نجاح المسارين. تعطيل بوابة التقدم بعد البداية يؤجل منحة سبق الوعد بها، ويحتفظ الحدث بموعده وسياساته عند إعادة المحاولة أو استعادة الغرفة.

## الأهلية والمبالغ

| الحالة | الخبرة | إكمال مؤهل للإتقان |
|---|---:|---:|
| إكمال عام وخسارة الفريق | 50 | 1 |
| إكمال عام وفوز الفريق | 70 | 1 |
| إكمال عام وتعادل | 60 | 1 |
| خاص ضمن أول ثلاث منح معتمدة في يوم النهاية UTC | 50، دون زيادة فوز أو تعادل | 1 |
| خاص بعد حد اليوم | 0 | 0 |
| انسحاب | 0 | 0 |
| تدريب أو مشاهدة أو إلغاء تقني | 0 | 0 |
| استيراد قديم معلّم | 0 | 0، ويظهر عداد تاريخي منفصل |

المقصي وفق قواعد المباراة ليس منسحبًا. مغادرته المتابعة بعد إقصائه لا تسقط أهليته. تعني «أول ثلاث» ترتيب اعتماد المنح ذريًا لذلك الحساب في يوم `finishedAt`؛ لا يوجد ترتيب عالمي لنهايات جميع الغرف عبر outboxes المتأخرة. تبقى نتائج الخاص بعد الحد في السجل. لا توجد نقاط لعدد الرسائل أو استعمال القدرات أو الشراء.

المستوى `1 + floor(XP / 250)`، وعتبات الإتقان 1 و5 و15 و40 و100 إكمال مؤهل للدور. هذه سياسة معاينة قابلة للمعايرة بإصدار جديد لمباريات لاحقة.

## الدفتر والحذف

ترحيل `0019_mafia_progress.sql` يضيف إيصالات دائمة ومجموع اللاعب ومجموع كل دور. مفتاح الإيصال `(user_id, match_key, match_completed)` واحد؛ المصدر وإصدار السياسة لا يفتحان حقًا في منحة أخرى. يدخل حجز الإيصال وتجميع الخبرة والإتقان وإنهاء الإيصال في `D1.batch` ذرية. تعارض البيانات الثابتة يحتاج مصالحة، ولا يجيز إسقاط الحدث أو مضاعفة المنحة.

لا يمس تنظيف الثلاثين يومًا الإيصالات أو المجاميع. تُحذف مع الحساب في معاملته، وتفحص كل كتابة صلاحية الحساب في SQL نفسه. لا ينشأ replay متأخر إلا عند إثبات اكتمال الحسابات وصلاحيتها؛ نتائج الآخرين مستقلة.

الاستيراد القديم يدوي واختياري ومحصور بالمعاينة. يبدأ `scripts/mafia-preview-progress-import.mjs` بفحص جاف، ويتطلب عقد قطع مؤكدًا ومقيدًا بالعامل وقاعدة المعاينة. يستورد نتائج محفوظة ذات دور معروف فقط، دون XP أو إتقان، ويميز عدادها التاريخي. لا يستنتج الدور من الإحصاءات العامة، ويستبعد مباريات السياسة الجديدة حتى إذا سبق الأرشيف صرف المنحة. تطابق العقد المقدم ليس إثباتًا حيًا مستقلاً لوقت التفعيل.

## ترتيب الإصدار

يجب تطبيق `0019` على **D1 المعاينة قبل رفع العامل B**؛ حتى حذف الحساب مع إغلاق بوابة التقدم يعتمد على الجداول الجديدة. لا تستخدم إعداد إنتاج أو أمر النشر العام. تحقق من سجل الترحيلات والنسخة النشطة قبل الخطوة وبعدها، واقرأ الحالة قبل أي إعادة محاولة غامضة. تبقى القواعد 1 والبروتوكول 2 والسعة غرفة واحدة و80 مشاركًا محجوزًا؛ لا يثبت ذلك حصة مزود الصوت.

## واجهات الدفعة C والخصوصية

تضيف `0020_mafia_profile_preferences.sql` تفضيلات لوحة مافيا، و`0021_mafia_achievements_cosmetic_grants.sql` الإنجازات والتراخيص المكتسبة. يجب تطبيق الاثنين في قاعدة المعاينة قبل رفع العامل C. يظل سجل المباريات المؤقت مستقلًا عن التقدم الدائم، وتضيف صفحة السجل مؤشرًا محدود العمر إلى حدها الافتراضي 50.

توفر `/api/mafia/catalog` معلومات الأدوار العامة والسياسة، وتعرض `/api/me/mafia/progress` تقدم صاحب الجلسة. يعرض `/api/profiles/:id/mafia` اللوحة وفق «أنا فقط» أو «أصدقائي» أو «الجميع»، مع الحظر في الاتجاهين وأقفال المباراة والصوت والمشاهدة. الإعداد الافتراضي خاص. هذا الإعداد يخص لوحة تقدم مافيا؛ تبقى إحصاءات ميدان العامة ضمن ملف اللاعب العام.

يقبل `PATCH /api/me/mafia/preferences` اختيار الظهور ودور ممثل تاريخي ثابت و`revision` فقط. يتطلب الدور إكمالًا مؤهلًا محفوظًا، ولا يُختار من الدور الجاري. الكتابة تعيد فحص الأهلية والأقفال والتعارض في SQL نفسه. لا ترسل الواجهة XP أو فوزًا أو تصنيفًا.

تعرض نهاية المباراة ملخصًا عبر `GET /api/me/mafia/rewards/:matchKey`، ويظل الرد `pending` بلا حقائق نتيجة قبل تأخير 30 ثانية أو عند عدم الملكية أو وجود قفل. معرف القراءة الصغير يظهر في حالة اللاعب المشارك عند النهاية فقط، ولا يدخل حالة المشاهد أو الحالة العامة أو التدريب. إعادة الفتح تقرأ المنحة نفسها، ولا تمنح أي شيء. تتجاهل الواجهة ردود الحساب أو الجلسة أو المباراة السابقة، وتخفي البيانات عند الخروج ولو بقيت هوية مخزنة مؤقتًا.

الإنجازات الأولية: أول مباراة مؤهلة، وأول فوز بكل فصيل نهائي، وثلاثة أدوار، والانتماءات النهائية الثلاثة. تمنح ثلاثة منها تراخيص `noir.frame` و`noir.nameColor` و`noir.cover` من الكتالوج الحالي. تدخل الجوائز في معاملة receipt نفسها، ولا يمنح legacy أو الانسحاب أو الخاص بعد الحد إنجازًا. مصدر الترخيص ظاهر في المتجر، ويعيد الخادم فحص صلاحية العنصر عند التجهيز. تبقى التراخيص بعد انتهاء بلس، ويظل إلغاؤها الخادمي محترمًا.

تحتفظ القراءات بحواجز نهائية للحساب الحي والخصوصية بعد التجميع، كي لا تُخرج بيانات جُمعت قبل حذف أو حظر أو بدء مشاهدة. تغطي الاختبارات سباقات القراءة والحفظ والمعاملات والمتصفحات. نجاح المصدر والمحلي وworkerd لا يثبت قبول آيفون أو جلسات توازن بشرية.
