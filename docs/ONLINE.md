# غرف ميدان — 1.4.1

تدعم الغرف «مين فينا؟» و«فبركة» من متصفحات الهواتف: المضيف يختار اللعبة وينشئ غرفة، والأصدقاء يدخلون برمز أو رابط أو QR. الخادم يحفظ حالة الغرفة ويحسب التصويت والنقاط. الواجهة تحتفظ بالهوية الصلصالية المعتمدة.

الرابط الحالي هو [ميدان على Cloudflare](https://maydan-game.mf103871.workers.dev/#/)، ويُحدّث من فرع `main`. ويمكن إبقاء الواجهة على GitHub Pages وتشغيل خادم غرف منفصل كما في الخطوات التالية؛ ملفات الواجهة وحدها لا تشغّل الغرف.

لنشر **اللعبة والخادم معًا على Cloudflare** اتبع `docs/CLOUDFLARE.md`؛ هذا الدليل يشرح الخيار الآخر: واجهة على GitHub Pages وخادم غرف منفصل.

## التفعيل المجاني على الإنترنت

تحتاج كمبيوتر عليه **Node.js 22 أو أحدث**، وحساب Cloudflare على **Workers Free**، ونسخة المشروع الكاملة أو تحديثًا منسوخًا داخل المشروع الموجود.

1. افتح الطرفية داخل مجلد المشروع الذي يحتوي `package.json` وشغّل:

   ```bash
   npm ci
   npx wrangler login
   ```

   تسجيل الدخول يفتح المتصفح لتختار حسابك. تتم المصادقة هناك؛ لا تحتاج وضع كلمة مرور أو مفتاح خاص في ملفات اللعبة.

2. راجع `wrangler.rooms.jsonc`. عنوان الموقع المسموح حاليًا هو `https://mf103871-boop.github.io`. إذا غيّرت نطاق الموقع، عدّل `ALLOWED_ORIGINS` إلى **أصل الموقع فقط**: البروتوكول والنطاق والمنفذ إن وُجد، بلا `/Maydan/` أو مسار آخر. افصل أكثر من أصل بفاصلة. بعدها شغّل بنفسك:

   ```bash
   npm run rooms:deploy
   ```

   هذا الأمر هو خطوة **نشر الخادم**. ينشئ Worker باسم `maydan-rooms` وربطي `ROOMS` و`LIMITERS` بقاعدة SQLite وفق ملف الإعداد، ويطبع رابطًا على `workers.dev`. لا تحتاج شراء نطاق. حافظ على خطة Workers Free؛ هذه التجربة لا تتطلب الترقية إلى Paid.

3. انسخ رابط Worker الحقيقي إلى `online.config.json`:

   ```json
   {
     "serverUrl": "https://maydan-rooms.YOUR-SUBDOMAIN.workers.dev"
   }
   ```

   استبدل المثال بالرابط الذي ظهر لديك، دون مسار أو علامة `/` أخيرة. هذا عنوان عام وليس مفتاح دخول. إبقاء القيمة فارغة يعرض رسالة «الغرف غير متاحة بعد».

4. ارفع ملفات المشروع المعدّلة بنفسك إلى مستودع Maydan. سير عمل GitHub Pages الموجود يبني الموقع عند الرفع إلى `main`. تأكد أن `online.config.json` المعدّل ضمن الملفات المرفوعة. افتح الموقع من ثلاثة هواتف، واضغط **«اللّمّة من كل جوال»**، ثم أنشئ غرفة وشارك الدعوة. كل لاعب يختار اسمه وشخصيته ويضغط **«أنا جاهز»**، ثم المضيف يضغط **«ابدأ اللعب»**.

إذا كنت ترفع الموقع إلى استضافة ثابتة أخرى، شغّل `npm run build` وارفع محتويات `dist` إلى استضافتك، مع ضبط أصلها في `ALLOWED_ORIGINS` وإعادة نشر الخادم. لا ترفع مجلد `server` إلى GitHub Pages على أنه خادم؛ الخادم يعمل على Cloudflare.

## ما الذي تفعله النسخة؟

| العنصر | السلوك |
| --- | --- |
| عدد اللاعبين | مين فينا: 3–12؛ فبركة: 3–8، بأسماء مختلفة داخل الغرفة |
| عدد الجولات | مين فينا: 5/8/12؛ فبركة: 3/5/7، أو دورة/دورتان للأصحاب |
| التصويت | 30 ثانية؛ في مين فينا تختار لاعبًا أو «لا أحد»، وفي فبركة تختار إجابة أو تمتنع ولا تختار إجابتك |
| تأكيد التصويت | اختيار محلي أولًا ثم زر تأكيد؛ لا يتغير التصويت بعد اعتماده |
| كشف النتائج | بعد اكتمال الأصوات أو موعد الخادم؛ مجاميع في مين فينا، وكشف تدريجي للإجابات والكتّاب والمصوّتين في فبركة |
| النقاط | مين فينا: نقطة لأكثر اللاعبين أصواتًا وللمتعادلين؛ قواعد فبركة أدناه |
| الانقطاع | عودة تلقائية بالمقعد نفسه من المتصفح نفسه؛ الصوت السابق يظل محفوظًا |
| إدارة الغرفة | تنتقل لأقدم لاعب متصل بعد 20 ثانية من اكتشاف غياب المضيف |
| الهاتف المختفي دون إغلاق الاتصال | يُرصد خلال نحو 45 ثانية دون نبض اتصال، ثم تبدأ مهلة المضيف |
| الخروج المقصود | يحرر المقعد؛ إذا بقي أقل من ثلاثة أثناء المباراة تنتهي بنتائج الجولات المكتملة |
| الانضمام المتأخر | اللاعب الجديد ينتظر عودة المجموعة إلى غرفة الانتظار |
| مدة الغرفة | ساعتان من إنشائها؛ ثم تنتهي وتُحذف بياناتها النشطة |

لا تُرسل الأصوات المعلّقة تلقائيًا بعد الانقطاع. عند العودة تظهر حالة الخادم: إن اعتمد صوتك ستراه، وإن لم يعتمد يمكنك التصويت ما دامت الجولة مفتوحة. تأخير الشبكة قد يجعل المؤقت يعرض الصفر قبل وصول النتيجة بقليل؛ قرار انتهاء التصويت للخادم.

فتح الغرفة في تبويبين من المتصفح نفسه يمثل **نفس اللاعب**؛ الاتصال الأحدث يحل محل الأقدم. امسح بيانات المتصفح فقط إذا كنت تريد فقدان مفتاح العودة. إذا فُقد المفتاح أثناء المباراة، لا يمكن استعادة هوية لاعب بمجرد كتابة اسمه.

## فبركة من كل هاتف

- **حقائق، صور، مزيج، أصحابنا:** نفس المحتوى والقواعد الأساسية لوضع الجهاز الواحد. الصور رسوم مدمجة، والمزيج يضع جولة صور كل ثلاث جولات. يمكن اختيار المواضيع ونوع الأسئلة.
- **الكتابة متزامنة:** 30 أو 45 ثانية، أو «براحتنا». المسودة تحفظ على هاتف صاحبها؛ يجب الضغط على «ثبّت إجابتي» لإرسالها. أول إجابة مثبتة لا تتغير، ولا يكشف الخادم أثناء الكتابة إن كانت صحيحة أو مكررة. عند انتهاء الوقت تتجاوز اللعبة الإجابات غير المرسلة. في الكتابة المفتوحة يستطيع المضيف إنهاء المرحلة.
- **النقاش والتصويت:** نقاش اختياري 15/20 ثانية ثم تصويت سري 30 ثانية. الإجابات المتطابقة تدمج، ولا يمكن التصويت للإجابة التي كتبتها، حتى بعد الدمج. يمكن ترشيح إجابة مضحكة بشكل مستقل بلا نقاط.
- **الكشف والنقاط:** المضيف يكشف الإجابات على دفعات، ويترك الحقيقة وأقوى فبركة للنهاية. الحقيقة وأسماء الكتّاب لا تُعلَّم مسبقًا في بيانات التصويت؛ تُحتسب النقاط مرة واحدة عند الكشف النهائي. اكتشاف الحقيقة يمنح 1000 نقطة وخداع كل لاعب يمنح 500. كل كاتب مؤهل لإجابة مشتركة يحصل على نقاط الخداع كاملة. مضاعفة الجولة الأخيرة اختيارية في غير «أصحابنا».
- **من كتب الحقيقة:** يحصل على نقاطها مرة واحدة، ولا يمنح تصويته الآخرين نقاط خداع في تلك الجولة. الصيغ البديلة والأرقام العربية والمكتوبة تطابق قواعد اللعبة المحلية.
- **المساعدة:** اقتراح واحد لكل لاعب طوال المباراة؛ حتى بعد تعديله لا تُحسب له نقاط خداع أو ترشيحات ضحك في تلك الجولة. يستطيع كسب نقاط الحقيقة ثم العودة لكسب نقاط الخداع في الجولات التالية.
- **أصحابنا:** صاحب الحقيقة يتناوب بين اللاعبين، وهو دور منفصل عن مضيف الغرفة. يكتب حقيقة عن نفسه سرًا خلال 90 ثانية، ويمكنه إضافة ثلاث صيغ صحيحة أو تبديل السؤال المتاح. لا يكتب فبركة ولا يصوّت ولا يكسب نقاطًا في دوره. غيابه عن تثبيت الحقيقة ينهي الجولة بلا نقاط.
- **العودة إلى الغرفة:** الإجابات المثبتة والأصوات والمساعدة وترتيب الخيارات تبقى محفوظة. المؤقتات يضبطها الخادم وتستمر عند إخفاء الصفحة. النتيجة النهائية تعرض النقاط وألقاب الجلسة وأفضل الفبركات.

## تجربة محلية قبل النشر

في طرفية أولى:

```bash
npm ci
npm run rooms:dev
```

الخادم المحلي يعمل على `http://127.0.0.1:8787`. في طرفية ثانية، على macOS أو Linux:

```bash
MAYDAN_ROOMS_URL=http://127.0.0.1:8787 npm run dev
```

في PowerShell بدل الأمر السابق:

```powershell
$env:MAYDAN_ROOMS_URL = "http://127.0.0.1:8787"
npm run dev
```

افتح `http://localhost:3000` في ثلاثة **متصفحات أو ملفات تعريف منفصلة**. التبويبات العادية تشترك في المقعد. إعداد متغير البيئة يخص البناء المحلي ولا يغيّر ملف عنوان الخادم العام. بيانات المحاكي المحلي تُفقد عند إيقافه؛ Cloudflare يستخدم التخزين الدائم طوال صلاحية الغرفة.

العنوان `localhost` ليس رابطًا لمشاركته مع هواتف أخرى. تجربة الهواتف عبر الإنترنت تتم بعد تفعيل Cloudflare ونشر الواجهة.

## الاختبارات وحدود التحقق

```bash
npm test
npm run test:rooms
npm run rooms:check
npm run build
```

- تشمل المجموعة اختبارات المنطق والشبكة وواجهات فبركة من لقطات الخادم الفعلية.
- تشمل الاختبارات مباراة كاملة من خمسة أدوار بين ثلاثة اتصالات WebSocket حقيقية، التصويت المتزامن، الخصوصية، التعادل، تكرار الطلبات، حدود الغرفة، الصلاحيات، فشل التخزين، انقطاع الشبكة، عودة المقعد، انتهاء الوقت والصلاحية، ونقل المضيف.
- اختبارات **Cloudflare workerd عبر Miniflare مع SQLite** تتمم مباريات كاملة لمين فينا وفبركة و«أصحابنا»، وتفرض إسبات الغرف ثم تكملها بالاتصالات المحفوظة؛ تتحقق من السرية والنقاط والعودة وتناوب صاحب الحقيقة.
- `rooms:check` يفحص إعداد Wrangler وحزمة الخادم باستخدام `--dry-run`؛ لا ينشرها.
- بعد النشر جرّب ثلاثة هواتف، وإغلاق شاشة أحدها والعودة، وتحقق من QR وصوت اللعبة وحجم الخط. الاختبارات الآلية لا تثبت جودة العرض على كل هاتف.

النطاق الحالي **متصفح الهاتف وPWA على HTTPS**. الغلاف الأصلي الموجود في مجلد iOS يحمّل ملفًا محليًا؛ ربطه بالغرف يحتاج معالجة أصل WebView واختبارًا مستقلًا. لا تضف `null` إلى الأصول المسموحة بغرض تشغيل الغلاف المحلي. كل الألعاب تحتفظ بوضع الجهاز الواحد؛ «مين فينا؟» و«فبركة» متاحتان أيضًا كغرف في هذه النسخة.

## حدود المجاني

تمت مراجعة [تسعير Durable Objects الرسمي](https://developers.cloudflare.com/durable-objects/platform/pricing/) في 12 سبتمبر 2026. SQLite Durable Objects متاحة على Workers Free؛ الحصص تشمل 100 ألف طلب يوميًا و13 ألف GB-s يوميًا، و5 ملايين صف مقروء و100 ألف صف مكتوب يوميًا، و5 GB تخزين إجمالي. كتابة الإنذارات تدخل ضمن حصة الكتابة. عند تجاوز حصة مجانية تفشل العمليات المقابلة؛ الحصص اليومية تتجدد عند 00:00 UTC. للخادم الأمامي أيضًا [حدود Workers الخاصة به](https://developers.cloudflare.com/workers/platform/pricing/).

هذه حصص استخدام، وليست عدد لاعبين مضمونًا. Hibernation والرد الآلي على نبض الاتصال يقللان استهلاك مدة التنفيذ. راقب الاستخدام من حسابك أثناء التجربة؛ النسخة لا تشغّل ترقية أو اشتراكًا مدفوعًا.

## تفاصيل للمطور

- `server/worker.mjs`: حدود الأصول والطلبات، توجيه الإنشاء والدخول، وتحديد معدل الطلبات حسب بصمة IP يومية.
- `server/room.mjs`: دورة Durable Object، حفظ ذري للحالة والإنذار، WebSocket Hibernation، المصادقة، وحالة الاتصال.
- `server/game-model.mjs`: اختيار منطق اللعبة، مع دعم غرف مين فينا القديمة دون حقل لعبة.
- `server/room-model.mjs`: العضوية المشتركة وقواعد مين فينا.
- `server/fabraka-model.mjs` و`server/fabraka-content.mjs`: مراحل فبركة، النقاط، تجهيز المحتوى، ولقطات البيانات الخاصة بكل لاعب.
- `src/online/`: الواجهة والعميل والقيم المشتركة. `online.config.json`: عنوان الخادم العام.
- `server/local.mjs`: محوّل HTTP/WebSocket محلي يستخدم منطق الخادم نفسه، بتخزين في الذاكرة.
- `tests/online-*.test.js`: اختبارات المنطق والشبكة ومحرك Cloudflare.
- `server/accounts/`: الحسابات والاشتراك؛ يُستدعى من `routeRequest` قبل مسارات الغرف. إنشاء الغرفة يُحسب مباراة للّعبة: المجهول مسموح دائمًا، والمسجّل غير المشترك يُرفض بـ`402 PLUS_REQUIRED` بعد مباراته المجانية، والدخول برمز مجاني للجميع. التفاصيل والأسرار وإعداد D1 في `docs/ACCOUNTS.md`.

مفتاح المقعد عشوائي بطول 256 بت، يخزن المتصفح أصله والخادم بصمة SHA-256. يُرسل في جسم طلب HTTPS أو أول رسالة WebSocket، وليس ضمن رابط الدعوة. المصدر الأساسي للهوية هو المقعد المصادق عليه، وليس أي معرّف لاعب يدّعيه أمر التصويت. لا تُرسل مفاتيح الآخرين أو ترتيب الأسئلة المقبلة في لقطات الغرفة. في فبركة لا تظهر الحقيقة أو أسماء الكتّاب أو أصحاب الأصوات قبل دفعة الكشف الخاصة بها. تستخدم خيارات التصويت معرّفات عشوائية لا تميز الحقيقة؛ بروتوكول فبركة 2 وبروتوكول مين فينا 1، مع طلب تحديث الصفحة للعميل القديم.

الاختيارات سرية عن **اللاعبين الآخرين**؛ الخادم يحتاجها لحساب النتيجة، وليست مشفرة طرفًا لطرف. تُحذف البيانات النشطة عند انتهاء الغرفة أو مغادرة الجميع؛ هذه العبارة لا تتضمن وعدًا بحذف سجلات البنية التحتية أو نسخ المزود الاحتياطية فورًا. الغرف بالرمز مخصصة لتجربة مع الأصدقاء، وليست نظام حسابات أو مباريات تنافسية عامة، وتحديد الطلبات الأساسي ليس حماية شاملة من إساءة الاستخدام.
