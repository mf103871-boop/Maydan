# صيغة حزم أسئلة «بَديهة»

كل حزمة ملف JSON واحد في `src/data/categories/`، ثم سطرا استيراد وإضافة في
`src/data/categories/index.js`. الوسائط (صور/صوت/فيديو) في `media/<pack-id>/`.

```json
{
  "id": "logos",
  "name": "شعارات",
  "icon": "🏷️",
  "style": "story",
  "qs": [ { "p": 200, "q": "…", "a": "…", "qid": "3f9a1c2b7e04" } ]
}
```

| الحقل | إلزامي | الشرح |
| --- | --- | --- |
| `id` | ✔ | حروف لاتينية صغيرة وأرقام فقط، ويطابق اسم الملف ومجلد الوسائط |
| `name` | ✔ | الاسم المعروض في اللوحة |
| `icon` | ✔ | إيموجي واحد |
| `style` | — | `"story"` لحزم المسلسلات والأنمي: تمنع الاختبارات أسئلة الإنتاج (مخرج، مؤلف، عدد المواسم…) وتُبقيها على أحداث العمل |
| `qs` | ✔ | 24 سؤالًا على الأقل، وفيها أسئلة بكل شريحة من 200 إلى 1000 |

## حقول السؤال

| الحقل | الشرح |
| --- | --- |
| `p` | النقاط: 200 أو 400 أو 600 أو 800 أو 1000 |
| `q` | نص السؤال |
| `a` | الإجابة المعروضة بعد الكشف |
| `qid` | 12 خانة ست عشرية، فريدة في البنك كله (سجل «لُعب سابقًا» يعتمد عليها) |
| `type` | نوع السؤال؛ غيابه يعني سؤالًا نصيًا عاديًا |
| `media` | ملف الوسائط أو مصفوفة ملفات (انظر أدناه) |

## أنواع الأسئلة

### نصية وبصرية بلا ملفات

| `type` | الحقول الخاصة | ما يظهر للاعب |
| --- | --- | --- |
| *(بلا نوع)* | — | نص السؤال فقط |
| `truefalse` | `a` = `"صح"` أو `"خطأ"` | العبارة وزرّا صح/خطأ، ويُبرَز الصحيح عند الكشف |
| `scramble` | `letters` (مصفوفة حروف مبعثرة) | الحروف مبعثرة، وتُرتَّب عند الكشف |
| `complete` | `q` فيه `___` مكان الفراغ | جملة بفراغ يُملأ عند الكشف |
| `common` | `items` (مصفوفة) | قائمة عناصر، والمطلوب القاسم المشترك |
| `hints` | `hints` (مصفوفة تلميحات) | زر «اطلب تلميحًا» — كل تلميح يخصم 25% من نقاط السؤال (بحدّ أدنى الربع) |
| `emoji` | `q` = الإيموجي، `hint` اختياري | سطر إيموجي يُخمَّن |
| `order` | `items` بالترتيب الصحيح | عناصر مبعثرة تُرتَّب |
| `odd` | `items`، و`odd` = فهرس الدخيل | شبكة عناصر، ويُبرَز الدخيل |
| `grid` | `grid` (مصفوفة صفوف)، و`target` | شبكة تركيز يُبحث فيها عن عنصر |
| `flag` | `flag` = وصف العلم | علم يُرسم بـ SVG (`t`: `h`,`v`,`circle`,`nordic`,`swiss`,`hoist`,`tri`,`kuwait`,`serrated`) |
| `sound` | `sound` = اسم مقطع مُولَّد | صوت يُركَّب في المتصفح: `doorbell, alarm, siren, horn, heartbeat, rain, clock, knock, helicopter, morse, sonar, laser` |
| `zoom` | `emoji` أو `image`، و`origin` اختياري | إيموجي/صورة مقرّبة جدًا تعود لحجمها عند الكشف |
| `pic` | `emoji` أو `image` | ظل أسود يتلوّن عند الكشف |

### أنواع الوسائط (ملفات حقيقية)

| `type` | `media` | `effect` | ما يظهر |
| --- | --- | --- | --- |
| `image` | ملف صورة | `none` (افتراضي) · `zoom` · `blur` · `silhouette` · `reveal` | صورة، والمؤثّر يزول عند الكشف |
| `audio` | ملف صوت | — | زر تشغيل/إيقاف وزر «من البداية»، ويُعاد السماع بلا حدّ |
| `video` | ملف فيديو | — | مشغّل بأدوات تحكّم كاملة |
| `diff` | مصفوفة من صورتين | — | الصورتان جنبًا إلى جنب، و`spot` يعلّم موضع الفرق عند الكشف |

- `effect: "zoom"` يقبل `origin` (مثل `"30% 35%"`) لتحديد نقطة التقريب.
- `effect: "silhouette"` يُسوّد الصورة بالكامل، فيصلح لصورة بخلفية شفافة
  (PNG/WebP) أو بيضاء؛ صورة بخلفية داكنة ستصير مربعًا أسود لا شكل فيه.
- `effect: "reveal"` يغطي الصورة باثنتي عشرة قطعة، وللاعبين كشفها قطعة قطعة.
- `spot` في `diff`: `{ "x": 50, "y": 50, "r": 14 }` — نِسَب مئوية من عرض الصورة.
- كتابة `q` مع أنواع الوسائط اختيارية: الترويسة تعرض عبارة النوع العامة، ونص
  السؤال يظهر فوق الملف فقط إن أضاف شيئًا جديدًا.

## الوسائط

```json
{ "p": 400, "type": "image", "effect": "blur", "media": "pepsi.webp", "q": "أي علامة تجارية؟", "a": "بيبسي", "qid": "…" }
```

- المرجع القصير (`"pepsi.webp"`) يكمله مجلد الحزمة: `media/logos/pepsi.webp`.
- `"media/shared/x.webp"` يشير إلى مجلد آخر، و`"https://…"` إلى استضافة خارجية.
- الامتدادات المقبولة: صور `webp png jpg gif avif svg` · صوت `mp3 m4a aac ogg opus wav` ·
  فيديو `mp4 webm mov`. المفضّل: **webp** للصور، **mp3** للصوت، **mp4** للفيديو.
- **البناء يفشل** إن أشار سؤال إلى ملف غير موجود، أو إلى امتداد لا يطابق نوعه.

## الإنترنت والتخزين

اللعبة نفسها تعمل دون إنترنت. الحزم ذات الوسائط تحتاج الشبكة **أول مرة فقط**:

- عند بناء اللوحة تُجلب ملفات الجولة في الخلفية، فلا ينتظر اللاعب عند فتح السؤال.
- في شاشة الإعداد يظهر صف «وسائط الفئات المختارة» مع زر «حمّل» يخزّنها في العامل
  الخدمي، فتُلعب بعدها بلا شبكة. الصف لا يظهر أصلًا للحزم النصية.
- الملف الذي يتعذّر تحميله يعرض رسالة وزر «أعد المحاولة» بدل مربع فارغ.

## حقوق الوسائط

لا تُضف صورة أو مقطعًا لا تملك حق نشره. المصادر الآمنة: ما هو في الملك العام،
ورخص المشاع الإبداعي التي تسمح بإعادة النشر، وما تصنعه بنفسك.
