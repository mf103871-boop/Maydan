## دمج main والبناء التلقائي

قراءة Cloudflare الرسمية في **11 نوفمبر 2026، 18:40 UTC** أكدت أن Workers Builds يراقب `main`، ويستخدم `npm run build:cloudflare` للبناء. أمر النشر الحي هو:

```text
node -e "console.log('Build only: production deployment requires the reviewed paired game+rooms release procedure.')"
```

هذا الأمر يطبع رسالة فقط. لا يرفع كودًا أو أصولًا أو يطبق ترحيلًا. تؤخذ قراءة جديدة قبل الدمج؛ لا يُفترض بقاء إعداد خارجي ثابتًا إلى الأبد. نشر GitHub Pages يدوي فقط، وبناء TestFlight الموقّع يدوي بمدخلات صريحة. لا تشغّل أيًا منهما لمجرد تحديث وثائق الإصدار.

الأمران `npm run cloudflare:deploy` و`npm run rooms:deploy` محجوبان بحارس الإنتاج. لا تستبدل أمر النشر الحي بهما أو بـ`wrangler deploy` لتجاوز الحارس. لا يُمنح تصريح نشر عام عبر تحديث README أو ملف الإصدار.

## تحديث المعاينة أو الإنتاج

اتبع [إجراء الحفظ والنشر المراجع](releases/production-paired-release.md). يحتاج أي رفع فعلي مصدرًا مجمدًا، وقراءة حية ونسخة احتياطية وخطة محدودة وبصمة ومراجعة مستقلة، مع حفظ كود العامل والموارد والأسرار والإعدادات والمواعيد والحسابات والغرف وStudio وبنك ارسمها الخاص. تحديث HTML وCSS وSW يحتاج رفع أصول مراجعًا؛ `keep_assets` وحده يحتفظ بالأصول السابقة ولا يحدّثها.

لا تنشر ملفات Warmth الخاصة المفكوكة على الويب، ولا تعِد استعمال مشغّل أو قفل محاولة سابقة. لا تنشئ DB أو R2 أو DO أو أسرارًا جديدة بدل الموارد الموجودة. أي نتيجة كتابة مجهولة تُصالح بالقراءة قبل قرار آخر.

خطة التحضير الخاصة بالبناء59 محفوظة في [سجل خطة59](releases/preview-web-1.9-build59.md) وقد نُفّذت؛ ليست إذنًا لإعادتها. تتضمن [نقطة التسليم](releases/CURRENT.md) ما تم التحقق منه وما ينتظر تجربة آيفون وإعلان حقيقي وعزل صوت بين الأجهزة.
