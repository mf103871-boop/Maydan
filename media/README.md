# وسائط الحزم

أنواع الأسئلة وحقولها كاملةً في [`docs/PACK_FORMAT.md`](../docs/PACK_FORMAT.md).
هذا الملف عن الملفات نفسها: أين توضع، وكيف يشير إليها السؤال.

كل حزمة لها مجلد باسم معرّفها، وملفاتها بداخله:

```
media/
  logos/     01.webp  02.webp …
  songs/     01.mp3   02.mp3  …
  posters/   01.webp  …
```

والسؤال يشير إلى الملف باسمه القصير فقط:

```json
{ "p": 400, "type": "image", "q": "ما هذا الشعار؟", "a": "بيبسي",
  "media": "01.webp", "qid": "a1b2c3d4e5f6" }
```

فيُبنى العنوان `media/logos/01.webp`. ويجوز بدل ذلك وضع عنوان كامل
(`https://…`) إن كانت الوسائط مستضافة في مكان آخر.

## ما يفحصه البناء

`npm run build` يتحقق من وجود كل ملف يشير إليه سؤال، **ويفشل** إن كان ناقصًا،
حتى لا يُنشر سؤال بصورة مفقودة. ويطبع حجم الوسائط لكل حزمة.

## التنسيقات

| النوع | المفضّل | لماذا |
| --- | --- | --- |
| صور | `.webp` | أصغر بكثير من png/jpg بالجودة نفسها |
| صوت | `.mp3` أو `.m4a` | مدعومة في كل المتصفحات |
| فيديو | `.mp4` (H.264) | يعمل على آيفون وأندرويد |

اضغط الصور إلى عرض 1200 بكسل كحد أقصى؛ الشاشة لن تعرض أكثر من ذلك، والحجم
الأصغر يعني فتحًا أسرع على بيانات الجوال.

## الإنترنت

الوسائط تُجلب من الشبكة أول مرة، ثم يخزّنها العامل الخدمي في مخزن مستقل
(`maydan-media-v1`) لا يُمسح عند تحديث اللعبة. ولمن أراد التجهيز مسبقًا: في شاشة
الإعداد زرّ «حمّل» يُنزّل وسائط الفئات المختارة دفعة واحدة، فتُلعب الجولة بلا
اتصال. الملف الذي يفشل تحميله يعرض رسالة وزر إعادة محاولة، ولا يوقف اللعب.

## تجربة المسار محليًا

`node scripts/demo-packs.mjs` يركّب ست حزم تجريبية تغطي كل أنواع الأسئلة
بوسائط اصطناعية من `tests/fixtures/`، و`--remove` يزيلها. مخرجاتها مُستثناة في
`.gitignore` ولا تُنشر.

## حقوق المحتوى

الصور والأصوات المأخوذة من أعمال محمية (أفلام، مسلسلات، أغانٍ، شعارات تجارية)
تخضع لحقوق أصحابها. للاستخدام العائلي الخاص الأمر مختلف عن النشر العام، فانتبه
لهذا قبل رفع اللعبة للناس.
